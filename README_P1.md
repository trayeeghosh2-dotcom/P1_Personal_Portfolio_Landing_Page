📒Project 01:Personal Portfolio Website

📌 Project Overview

This project is a responsive Personal Portfolio Website created using HTML, CSS, and JavaScript. It showcases personal information, educational background, technical skills, projects, internship experience, and contact details.

The website is designed to present my profile and skills in a professional and attractive way.

✨ Features

- Responsive navigation bar
- Attractive home/hero section
- About Me section
- Technical Skills section
- Educational Qualifications
- Internship and Experience section
- Projects showcase
- Contact section
- Smooth scrolling and animations
- Mobile-friendly design

🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling, layout, animations and responsive design
- JavaScript – Interactive functionality

💻 Tools Used

- Visual Studio Code
- Live Server Extension
- Web Browser (Google Chrome)

📂 Project Structure

Project_01_PersonalPortfolio/
│
├── portfolio.html
└── README_P1.md

All HTML, CSS, and JavaScript code is included in a single HTML file.

🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open the "portfolio.html" file.
4. Right-click and select Open with Live Server.
5. The portfolio website will open in your browser.

You can also open "portfolio.html" directly in any modern web browser.

🎯 Objective

The main objective of this project is to build a professional online portfolio that highlights my academic background, technical knowledge, projects, and professional experience.
